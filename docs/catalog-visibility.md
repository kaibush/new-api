# 模型可见性

超级管理员在「系统设置 → 安全与限制 → 模型可见性」管理可见范围。入口是 `/system-settings/security/model-visibility`，与分组定价独立。权限组按账号 ID 管理，一个账号可以加入多个权限组，不需要更改用户或令牌的计费分组。

例如：新建权限组 `staff`，搜索并添加内测人员。把模型 `preview` 和路由分组 `internal` 加到受限资源中，只允许 `staff` 查看，保存更改。即使普通用户和内测人员都在同一个定价分组、共用一个公开模型，普通用户也不会看到 `internal` 分组标签。访客不属于任何权限组。

- 没有规则的资源沿用现有权限。受限资源的允许列表为空时，对所有成员隐藏；删除最后一个有权查看的权限组不会意外公开资源。移除资源规则则恢复原有权限。
- 规则只收窄现有权限，不会增加渠道、改变计费或让不可路由的模型变得可调用。管理后台维护资源的权限不变。
- 目录、令牌模型列表和详情、排行榜、性能统计按查看者过滤；公开倍率同步在配置了限制时只同步访客可见的模型。自动路由同样不能选择被限制的分组。
- 已经被用户看到或导出的名字无法收回。历史账单、用户自己输入的内容，以及管理员手写的公告、描述和外部监控名称，不作为可见性规则管理的资源目录。
