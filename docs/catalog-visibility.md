# 模型可见性

超级管理员从「用户管理 → 权限组」进入 `/users/permission-groups`。用户列表和模型管理页也有「权限组」快捷入口，旧的系统设置链接会跳转到同一页。权限组与定价分组独立，按账号 ID 管理，一个账号可以加入多个权限组。

点击「新建权限组」，在弹框里填自定义名称（例如 `内测组`），按用户名或 ID 搜索并添加成员，选择受限模型 `preview` 和受限路由分组 `internal`，点击「新建」即生效。手机上可以滚动表单，底部保留操作按钮。编辑时可改名、移除成员或调整资源；取消不会写入。即使组外账号使用同一定价分组，也看不到仅授权给内测组的资源。访客不属于任何权限组。

已有权限组、成员和允许规则无需迁移。没有配置排除名单的资源保持原有行为。

**默认可见，只排除少数账号：** 在「受限模型」或「受限路由分组」点「添加规则」（已有规则点「编辑」），选中资源，将「可见范围」改为「默认可见，排除指定账号」，按用户名或 ID 搜索并添加要排除的账号，保存即可。无需创建权限组。其余已有访问权限的登录账号（包括以后新增的账号）沿用正常权限，不会因此获得额外渠道或定价分组。设置排除名单后，访客也看不到该资源，以免被排除的账号退出登录后仍能看到名称。

**仅指定权限组可见：** 保持「仅指定权限组」模式，可另外排除个别成员。排除优先，即使账号在允许的权限组里也看不到或无法调用相应资源；删除权限组不会删除排除名单。不选任何允许组则对所有人隐藏。默认可见模式至少要有一个排除账号，要彻底恢复原可见性，点「解除限制」并确认。

- 没有规则的资源沿用现有权限。受限资源的允许列表为空时，对所有成员隐藏；删除最后一个有权查看的权限组不会意外公开资源。移除资源规则则恢复原有权限。
- 规则只收窄现有权限，不会增加渠道、改变计费或让不可路由的模型变得可调用。管理后台维护资源的权限不变。
- 目录、令牌模型列表和详情、排行榜、性能统计按查看者过滤；公开倍率同步在配置了限制时只同步访客可见的模型。自动路由同样不能选择被限制的分组。
- 已经被用户看到或导出的名字无法收回。历史账单、用户自己输入的内容，以及管理员手写的公告、描述和外部监控名称，不作为可见性规则管理的资源目录。
