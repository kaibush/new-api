# 模型与路由分组权限控制

超级管理员可从「模型管理 → 权限」(`/models/permissions`) 或「用户管理 → 权限组」(`/users/permission-groups`) 统一配置模型与路由分组访问权限；也可在模型管理表格中直接点击单行「访问权限」徽章或勾选多行批量配置。权限组按账号 ID 管理，与计费分组独立，一个账号可同时加入多个权限组。

新建权限组只需填写名称，成员和资源都可以留空。在模型或路由分组的权限规则中，可把同一组用于不同资源的「允许的权限组」或「排除的权限组」，不需要复制成员名单。空组不会匹配任何账号：白名单只有一个空组时无人获准，排除空组则不会排除任何人。以后变更成员，所有引用该组的规则随之生效。选择组内成员、允许账号或排除账号时，都可在同一次搜索中连续勾选或取消多个账号，最后保存。

## 四种访问模式

每个模型或路由分组均支持四种访问模式，且**排除规则始终优先于允许规则**（`Deny > Allow`）：

1. **对所有登录用户开放（可选排除）**：所有已登录用户默认可见并可调用，支持按权限组或单个账号排除。即使排除列表为空也可保存，用于将私有渠道分组中的模型直接开放给全体登录用户。
2. **仅白名单可见**：仅允许选定的权限组或直接指定的账号查看并调用，无需为了少量账号单独建组；同样支持叠加排除组或排除账号。
3. **对所有人隐藏（禁用）**：从所有模型列表与广场中隐藏，并拦截 API 调用。当系统中存在此类规则时，权限面板顶部会醒目提示，支持一键筛选与恢复默认。
4. **默认（跟随路由分组）**：不设置覆盖规则，沿用常规渠道分组与用户可用分组（`UserUsableGroups`）配置。

## 跨分组展示与直连调用

- 只要某个模型（或其所在渠道分组）通过权限规则对当前登录用户放行且未排除该用户，无论该用户的常规 API 令牌绑定的是 `default`、`openai`、`claude`、`auto` 还是留空，均可在模型广场（`/api/pricing`）、Playground（`/api/user/models`）与令牌模型列表（`/v1/models`、`/v1beta/models`）中直接看到该模型并正常发起调用，无需管理员把私有渠道分组加入全局 `UserUsableGroups`，也无需用户改绑令牌分组。
- 若令牌本身开启了 `model_limits` 模型白名单，令牌白名单依然生效；计费时跨组回退命中的私有分组按所选渠道分组倍率结算（未单独配置分组倍率时默认为 `1.0`）。
- 凡受权限规则管控的模型或路由分组，未登录访客（`userID <= 0`）均不可见、不可调用。
- 删除权限组时，若某白名单资源不再剩余任何允许组或直接允许账号，默认保持隐藏以防误公开，弹窗中也可勾选「同时将受影响资源恢复为默认访问权限」一键恢复。
